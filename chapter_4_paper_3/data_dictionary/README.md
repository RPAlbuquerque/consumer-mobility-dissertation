# Data Dictionary

`data_dictionary_mobility_market_access.xlsx` documents the principal supplied, preprocessed, and notebook-derived fields used in Chapter 4.

The workbook separates each field's definition from its analytical role and interpretation boundary. It also records that the four `q1`-`q4` partitions represent weeks within August 2024, that the retained MII was constructed before the notebook's PCA checks, and that the 100 m values are conditional allocations rather than mobility observations at that resolution.

The dictionary describes the expected structure of the restricted analytical input without reproducing empirical records, provider metadata, individual trajectories, device histories, or personally identifiable information.
