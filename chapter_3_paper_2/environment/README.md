# Computational Environment

The notebooks were written in Python and use the packages listed in `requirements.txt`. Because the empirical inputs are restricted, the public copies were checked for valid notebook structure, portable paths, cleared outputs, and syntactically valid Python cells, but they were not rerun from raw data in the public repository.

Create an isolated environment, install the requirements, and launch Jupyter from either the `chapter_3_paper_2` directory or its `notebooks` directory. Full execution also requires authorized inputs arranged as described in `../data/README.md`.

The dependency ranges record a compatible analytical stack rather than an exact reconstruction of the original restricted computing environment, whose complete lockfile was not archived.
