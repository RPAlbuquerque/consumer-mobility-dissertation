# Public Notebook Notes

The notebooks in this directory are public analytical copies prepared from the restricted working notebooks. The following changes were made for responsible release:

- cleared cell outputs, execution counts, and environment-specific metadata;
- replaced private absolute paths with project-relative locations under `data/private/`;
- removed personal computing-account names and file-name references that could identify the focal manufacturer;
- removed inline package-installation commands in favor of `environment/requirements.txt`;
- excluded abandoned causal-effect and preliminary flexible-model experiments that do not support the dissertation's observational claims; and
- reframed the retained overlap check as a descriptive support diagnostic rather than a treatment-effect procedure.

No empirical observations, raw messages, device histories, individual trajectories, transaction records, credentials, or personally identifiable information are embedded in these notebooks.

Users with authorized access to the restricted inputs should not commit executed notebook outputs. Selected validation cells may display restricted source fields locally, so outputs must be cleared before any public commit.

These adaptations do not change the intended analytical interpretation of the dissertation. They make the public code inspectable without implying that restricted data are openly reproducible or that exploratory analyses excluded from the final study constitute reported evidence.
